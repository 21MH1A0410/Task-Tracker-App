# Task Tracker App

A premium, aesthetically pleasing Task Tracker designed for "Calm Productivity". Built with React, Vite, and modern CSS.

## Features

- **✨ Premium UI**: Glassmorphism effects, smooth transitions, and a calming color palette.
- **📝 Task Management**: Easily add, edit, and delete tasks.
- **✅ Interaction**: Click on the checkbox or the task name to toggle completion.
- **📊 Progress Tracking**: Visual daily progress bar keeps you motivated.
- **💾 Auto-Save**: Tasks persist automatically using Local Storage.

## Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS (Variables, Flexbox, Animations)

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start the development server**:
    ```bash
    npm run dev
    ```

3.  **Open the app**:
    Visit `http://localhost:5173` in your browser.

## Project Structure

- `src/components`: Reusable UI components (TaskItem, TaskList, ProgressBar).
- `src/hooks`: Custom hooks for logic (useTasks, useLocalStorage).
- `src/App.jsx`: Main application layout.
